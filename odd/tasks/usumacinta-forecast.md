# Tabasco river forecast

Rebuild the river stage forecast from scratch, documented end to end like the flood
susceptibility map. Start with the Usumacinta at Boca del Cerro (BDCTB), then extend to
the rivers of the IPCET semáforo. Mirror: Engram `odd/usumacinta-forecast/tasks`.

- **S5** Agreed data roles (L5, revised in L29): station levels and station rainfall from the CONAGUA SIH are used to train and validate; the forecast uses public gridded data (GloFAS, satellite and forecast rainfall) and, since L29, the publicly published IPCET daily 06:00 stage as a live input, with a GloFAS-only fallback when it is missing. The target is never imputed.
